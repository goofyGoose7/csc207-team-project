## Project Description
### Entertainment
Guess the city game where a user is shown a satellite image of a city with 5 tries to guess correctly, slightly zooming out with each wrong answer.

---
## User Stories
### User Story 1 - Felix
Users are shown a welcome page where they can start a new game or view their profile.
### User Story 2 - Elliot
As a user, I want to be told when my guess is correct and shown a screen displaying information about the correctly guessed location.
### User Story 3 - Nikola
Users have multiple guesses if they're incorrect. The image zooms out to show the city more clearly with each incorrect guess.
### User Story 4 - Regan
Users have accounts with a unique username, a profile picture, and a rating (like in chess). Accounts are editable.
### User Story 5 - Ingrid
As a player, I want to be able to view my rating and a leaderboard of the ratings of the top players of the game to see how good I am, relatively, at the game.
